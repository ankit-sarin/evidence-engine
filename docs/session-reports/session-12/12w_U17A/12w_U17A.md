### Q7 — Where the refusal fires (option table in §3)

`open_run`'s order (run_manifest.py:314–425): run kind → `CodebookReviewMismatch` → `DirtyTree` →
`AmbiguousEngineState` → `CloudArmNotEnabled` → arm registry (`PreManifestArm`, `RetiredArm`) →

`SAVEPOINT open_run` → the INSERTs. Every refusal before the SAVEPOINT writes no row. A family check fits

read, i.e. inside or after `resolve_run`, which already fetches `/api/tags` per model.

`run_pipeline` and the FT CLI exit as they do for the others. Its message must name the stage pair (e.g.

(spec field / server field), and the clearing action (declare a cross-family auditor, or a new arm).
The reproducer catches the base `RunRefused` so it presupposes no class name.

1. **On HEAD, an auditor identical to the extractor opens a run.** `repro/repro_run_head.txt`:
   "Failed: DID NOT RAISE <class 'engine.core.run_manifest.RunRefused'>" for `auditor_model =
   deepseek-r1:32b`. INT-i12-45's text is confirmed in its strongest form.
2. **The server's family string is an architecture id, not a lineage.** `q3/`: deepseek-r1:32b
   `"family": "qwen2"`, qwen3:32b `"family": "qwen3"`, qwen2.5vl:7b `"family": "qwen25vl"`, qwen3.5:27b
   `"family": "qwen35"`. An equality check on it reads deepseek-r1:32b vs qwen3:32b as cross-family.
3. **deepseek-r1:32b is a Qwen-base distillation by its own metadata.** `"general.architecture":
   "qwen2", "general.basename": "DeepSeek-R1-Distill-Qwen"`, `"tokenizer.ggml.pre": "deepseek-r1-qwen"`.
   The architecture doc labels it "(DeepSeek)" (`models.md:37`).

   "if stage in _LOCAL_EXTRACTION_STAGES" (run_manifest.py:233–234); `--skip-to audit` declares
   `("audit",)` (run_pipeline.py:492). A check over declared stages misses this start.
5. **A required family without a default breaks every omitted block.** `audit: AuditModels =
   Field(default_factory=AuditModels)` (review_spec.py:808); the live spec has no `audit:` key.
6. **`model_copy` bypasses spec validation.** 50 `model_copy(update=` sites in tests/ and
   `pin_tuples.py`'s `spec0.model_copy(update={"extraction_models": …})`; the reproducer builds its
   same-family spec that way.

   as `extractor` and `arm.model` could before `_arms_consistent`.

   exists to measure.

   (Alibaba/Qwen)" (ft_screener.py:3) against the live `primary: "qwen3:32b"`.
