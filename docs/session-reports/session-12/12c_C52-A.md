## Q5. Proposal (no edits): the C41 pattern per site

In every case: `cfg` becomes a required keyword-only parameter, the fallback line is deleted, and
callers pass a spec-built `cfg`. Tests pass an explicit `stage_config("<stage>")`, spec-less on purpose,
as at `2f87855`.

**Site 1.**
- `_retry_snippet` and `_validate_and_retry_snippets` take `cfg` required keyword-only (the latter only
  passes it through).
- Callers needing `cfg=`:
  - `scripts/q8_validation.py:60`: spec in reach, from `extract_single(paper_id, paper_text, spec: ReviewSpec)`; pass `stage_config("extract_retry_snippet", spec)`.
  - Tests `test_extractor.py:390, 409, 425, 443`.
- Already passing: `extractor.py:468`, `:585`; `test_extraction_run_link.py:186`.

**Site 2.**
- `parse_with_vision` takes `cfg` required keyword-only.
- `_run_parser`'s `**(vision_opts or {})` could then fail when `vision_opts` is None. Its only caller
  passes a built `vision_opts`, so this is safe; flagged for the implementer.
- Callers needing `cfg=`:
  - `scripts/test_extraction_validation.py:113`: spec in reach, from `process_paper(…, spec, …)`.
  - Tests `test_vision_bounds.py` (nine calls) and `test_undeclared_override.py:167`.
- **F1 (separate decision):** `parse_all_pdfs` and `_stage_parse` would gain a `spec` parameter, passed
  on to `parse_pdf`.
  - `run_pipeline` has a spec in reach.
  - **`scripts/parse_expanded_corpus.py` loads no spec.** It would need a `load_spec_for(review)`, a
    behaviour change for that script, or it stays spec-less by design. **No spec in reach today.**

**Site 3.**
- `semantic_verify` and `audit_span` take `cfg` required keyword-only. The `model=` override path
  (`if model is not None and model != cfg.model: cfg = cfg.with_model(model)`) stays.
- Callers needing `cfg=`:
  - `scripts/smoke_test_fixes.py:122`: spec in reach, `spec = load_spec_for(review, args.spec)` at `:50`.
  - Tests `test_auditor.py:142, 158, 176, 195, 215, 230, 254, 274`; `test_audit_events.py:212, 224`;
    `test_non_value_tokens_downstream.py:115, 119, 129`.
- Already passing: `audit_events.py:143`, `auditor.py:190`, `test_request_capture.py:216`.

**Site 4.**
- `_classify_page` takes `cfg` required keyword-only.
- No caller changes: `pdf_quality_check.py:218` and `test_request_capture.py:306` already pass it.

**Callers with no spec in reach:** only `scripts/parse_expanded_corpus.py`, under F1. Every
site-level caller has a spec in scope.
