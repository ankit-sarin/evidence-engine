# Architect briefs and rulings

This directory holds the architect's briefs and rulings, archived verbatim by the PI.

- **Verbatim.** A file here is the text as issued. It is not summarised, reformatted or
  tidied on the way in.
- **Never edited after commit.** Once a brief or ruling is committed it is immutable. A
  brief that turned out to be wrong stays wrong here, because the record of what was
  asked is what makes a session's response readable later.
- **Corrections are dated addenda.** A correction, a superseding ruling or a
  clarification is a new file, dated, naming what it supersedes — never an edit to the
  original.

The same rule governs `docs/session-reports/` as a whole: read-outs are never edited
after commit; addenda only.
