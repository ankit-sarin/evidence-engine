R734(c) — U19's design, commit 1 (O1 with O6(a)), from the read-out's quoted code:
  (i) Before `open_run`, the configured environment is read once (the `Environment=` value as
      `systemctl show` prints it, the raw string) by a reader in `ollama_preflight.py` that returns
      the raw string beside the parsed map, and `run_pipeline` passes it to `open_run` as an
      optional keyword recorded under one new body key, in `selection_bound` / `inputs`' form
      (absent, no key; covered by `manifest_sha256`); every production `open_run` caller that is a
      model-calling entry point passes it (CC lists the callers and reports which do), import
      manifests do not. No migration. The stage-start check (S5–S7) is unchanged; the open read is
      a record, not a second gate.
  (ii) After a PERFORMED proactive restart, and only then, the environment check runs before the
      next paper: `restart_ollama` returns whether it restarted; the extract loop (S9) runs the
      check on a true return. A skip is not a restart and triggers no check; T3's counter rule
      stands (F5). A correctness-tier drift on that read raises a `RunRefused` subclass carrying
      the keys with expected and actual (R727(b)'s message form beside `ModelDigestChanged`'s),
      which S9's `except RuntimeError` does not catch (F3); `run_pipeline` closes it 'aborted' with
      `reason=str(exc)` in the branch form `ModelDigestChanged` takes (CC quotes the branch; the
      architect writes no clause). The class joins the run-fault tuple and `RUN_REFUSED_MEMBERS`.
      A performance-tier drift after a restart is logged as at the stage start.
  (iii) Every post-restart read, pass or drift, writes one `run_telemetry` event (O6(a)) carrying
      the raw string and the verdict; a drift's keys also reach `end_reason` through (ii). No table.
  (iv) The two tests pinning "a restart failure continues the run" keep their assertion: a failed
      RESTART still continues (R7's graceful degradation); a drift READ after a successful restart
      stops. The acceptance test is the entry's, `test_the_env_check_runs_again_after_every_restart`,
      with its three clauses as separate ids, plus: a skip does not re-check; the body carries the
      string at open and `_BODY_KEYS` is unchanged for a body opened without it.
