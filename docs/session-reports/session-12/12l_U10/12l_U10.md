# 12l-U10 — a codebook that names another review is refused at run open (INT-i12-9)

## I1, I2

- **I1 holds.** Every caller of `open_run` passes the codebook beside the database it runs against, which is the file its prompts are built from:

  | caller | the codebook it passes | where its prompts' codebook comes from |
  | --- | --- | --- |
  | `scripts/run_pipeline.py::_open_run_manifest` | `load_codebook_beside(db.db_path)` | the extract path loads `Path(db.db_path).parent / "extraction_codebook.yaml"` (`extractor.extract_paper`, `pipeline._codebook_path`); the same resolved path, so the loader's cache returns the same object |
  | `scripts/run_cloud_extraction.py::run_arm` | `load_codebook(Path(db_path).parent / CODEBOOK_FILENAME)` | `CloudExtractorBase.__init__`: `self._review_dir = Path(db_path).parent`, `self._codebook = load_codebook(self._review_dir / CODEBOOK_FILENAME)` — the same path |
  | `engine/agents/ft_screener.py` (the FT run's manifest) | `load_codebook_beside(db.db_path)` | the FT prompts are built from the spec, not the codebook |
  | `engine/adjudication/import_screening_entry.py`, `ft_screening_adjudicator.py`, `import_extraction_entry.py` (kind `import`, no stages) | `load_codebook_beside(review_db.db_path)` | no prompt |
  | `run_manifest.open_review_session` | its `codebook` argument, passed to `open_run` | no prompt; no engine caller (tests only) |

  No caller opens a manifest with a codebook other than the one it sends from.
- **I2: a codebook with no `review` key does not load.** `engine/core/codebook.py`'s validation requires the key and refuses an empty one: `for key in ("escape_token", "contract_unmet_token", "review", "version"): if not str(doc[key] or "").strip(): raise CodebookError(f"Codebook at {path}: \`{key}\` must be a non-empty string.")`. So a loaded `Codebook` always declares a review. The refusal for "declares no review" is built all the same, for an object that reaches `open_run` another way.

## What changed

`engine/core/run_manifest.py` only:

- **`CodebookReviewMismatch(RunRefused)`**, a ninth member.
- **`open_run`**, directly after the run-kind check and before the git state is read, anything is resolved, or any row is written: `codebook.review` (stripped) must equal `spec.review_id`. Otherwise it raises, naming the codebook's path, the review it declares (or "declares no review") and the run's review id, and saying what to read and what clears it: the `review:` line of that file — a copy made under R235 whose `review:` was not changed is set to the run's id; another review's codebook is replaced by this review's.

Every `RunRefused` subclass is a run fault by the predicate; no change there. `engine/core/codebook.py` was not edited.
