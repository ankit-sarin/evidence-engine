## §7 Limits

- **Five cases.** The paired difference rests on one case (12g_p10); one more case changing direction
  would change the verdict.
- **Not independent sends.** k = 5 did not give independent sends (§6), so the rates measure
  stability under repetition, not a per-call probability.
- **12g prompt drift.** The 12g cases' attempt-1 prompt is today's, not 12g's (12v_U37R §1).
- **Server state differs from the real loop.** In the real loop attempt 2 follows the same paper's
  attempt 1, whose prompt is attempt 2's prefix. Here each send followed the other arm's request,
  which shares the prefix up to the feedback. Which server state the real loop resembles is not
  established here.
- **A concurrent GPU encode** ran during part of the window (§2).
