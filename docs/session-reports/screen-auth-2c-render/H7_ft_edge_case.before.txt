Papers describing bench/preclinical autonomous tasks (e.g., suturing, knot-tying on phantoms) are included regardless of the specialty context, as these represent generalizable autonomous capabilities. Orthopedic and neurosurgery papers are excluded only when the autonomous task is specialty-specific (e.g., autonomous bone drilling, stereotactic targeting). If the paper describes a generalizable autonomous task performed in an orthopedic or neurosurgical context, include it. These papers were flagged because the primary screener and verifier disagreed. Review the full-text reason code and both rationales to make your decision.
