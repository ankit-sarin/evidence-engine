## 1. The design (Phase 1, accepted by R681(d))

The guard sits in `audit_run` after the empty-todo `continue` and before `claim_text_ref` /
`read_parsed_text`, so before any text read, locate or verify. It reads the paper's state once, through
`effective_state` (the one reader, I2); the same value stamps the `audited` event's `from_state`, and the
later read (formerly after locate and verify) is removed. Nothing writes a paper event between the two
points, so an admitted paper's `from_state` is the value it was.

Two clauses of 12s_U15A §11 were ruled at the Phase 1 stop:
- **T7** (§11 item 7, "(if (B) or (C))") has no form under option (A). It is INT-s12-2's acceptance test
  and is not built here (R681(b)); k = 12.
- **T5** is built as §11 states it (R681(c)): the WARNING line names id, state and reason, and
  `AuditReport` gains a field listing the skipped papers.
