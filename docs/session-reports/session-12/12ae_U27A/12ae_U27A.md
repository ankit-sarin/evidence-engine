### 2e. Questions the inputs raise that Phase A does not answer

1. Is a provider outage a run fault? 3. Should the non-retryable provider errors (`BadRequestError`, `NotFoundError`, `PermissionDeniedError`) stop the retry like `AuthenticationError` (census #25's suggestion)? Not a tuple question; outside U27 as entered.
4. Does `run_arm` close a run-fault exit `failed` (today) or `aborted` (option C)?
